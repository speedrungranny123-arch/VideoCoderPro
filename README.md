VideoCoderPro 🚀
VideoCoderPro is a lightweight and fast C# video encoder based on FFmpeg. Designed for speedrunners to easily upscale and convert videos to 480p, 720p, 1080p, 2K, or 4K at various FPS settings.

📖 Instructions
Run the tool: Start the VideoCoderPro.exe file.

Select a file: Drag and drop your .mp4 or .mov file into the command prompt (cmd) and press Enter.

Choose Quality: Use the numbers to select your desired resolution.

Choose FPS: Select the frame rate.

Start: Press Enter to begin encoding.

Note: The process speed depends on your selected quality and hardware.

📁 Output
When finished, a new file named FileName_Quality.mp4 will appear in the same folder where the .exe program is located.
